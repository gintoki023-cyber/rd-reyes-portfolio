# R-D C. Reyes Portfolio

Personal portfolio website for R-D C. Reyes.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named `rd-reyes-portfolio`.
2. In GitHub Pages settings, select **Deploy from a branch**, then select the `main` branch and `/ (root)` folder.
3. The portfolio will be available at `https://<github-username>.github.io/rd-reyes-portfolio/`.

## Local preview

Open `index.html` in a browser.
